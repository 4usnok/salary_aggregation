# Алгоритм агрегации статистических данных о зарплатах сотрудников
Алгоритм агрегации статистических данных о зарплатах сотрудников компании по временным 
промежуткам, интегрируемый в тг-бота

## Стэк: Git, ORM, OpenAPI Docs, PEP8, Readme, Tests, Async, FastAPI, JSON, MongoDB, aiogram

## Содержание проекта
1. `handlers` - директория в которой хранятся файлы с логикой работы хэндлеров для тг-бота
2. `src` - директория в которой хранится основной исходный код проекта
3. `tests` - директория для тестов
4. `.env.sample` - Заполняется в первую очередь(предназначен для заполнений host, port, пароля от бд, названия бд и тд.)
5. `flake8` - файл с настройками для линтера flake8
6. `.gitignore` - текстовый файл, который указывает системе контроля версий Git, какие файлы или папки нужно 
игнорировать и не отслеживать в репозитории
7. `README.md` - описание проекта
8. `run_bot.py` - запуск тг-бота

## Запуск программы
Запуск тг-бота осуществляется из файла `run_bot.py`
